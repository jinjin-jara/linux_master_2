    🔐 파일 시스템 관련 명령어

    1-1. 소유권 — chown · chgrp

    파일에는 주인(소유자)과 소속(그룹)이 붙어 있습니다. 이걸 바꾸는 명령이 둘입니다.

    명령바꾸는 것예시
    chown소유자 (그리고 그룹까지)chown ihd test
    chgrp그룹만chgrp project test
    • chown ihd:project test — 소유자를 ihd, 그룹을 project로 동시에 변경
    • chown :root test — 콜론만 붙이면 그룹만 변경 (chgrp와 같은 효과)
    • -R : 하위 디렉터리까지 전부 (recursive) — chown -R root ihd
    • chgrp -h : 심볼릭 링크 파일 자체의 그룹 소유권을 변경

    1-2. 허가권 — chmod와 ls -l 읽기자주 22문항

    ls -l 결과의 맨 앞 10글자가 파일 유형 1글자 + 권한 9글자입니다.

    -rwxr-xr-x  2 root project 4096 Apr  6 10:22 project
 │└┬┘└┬┘└┬┘
 │ │  │  └── others(기타 사용자)
 │ │  └───── group(그룹)
 │ └──────── user(소유자)
 └────────── 파일 유형
    기호파일 유형
    -일반 파일
    d디렉터리
    l심볼릭 링크
    b블록 장치 (하드디스크 등)
    c문자 장치 (입출력 장치)
    s소켓
    p파이프(FIFO)

    chmod 사용법 2가지

    • 숫자 방식 — r=4, w=2, x=1을 더합니다. chmod 666 a.txt → rw-rw-rw-
    • 문자 방식 — 대상(u g o a) + 연산자(+ - =) + 권한(r w x)
      • chmod u-x file — 소유자의 실행 권한 제거
      • chmod a=rx file — 모든 사용자에게 읽기·실행만 부여 (나머지는 제거)
      • chmod -R o+w TST — TST와 그 안의 모든 파일에 기타 사용자 쓰기 권한 추가
      • chmod g=r lin.txt — 그룹 권한을 읽기만으로 설정
    bash
    root@linux-master:~# ls -l lin.sh  # 현재 권한 확인
-rw-rw-r--  1 ihd ihd 1079 Jan 27 16:29 lin.sh
root@linux-master:~# chmod 755 lin.sh  # 숫자 방식 — rwxr-xr-x
root@linux-master:~# chmod u-x,go+r lin.sh  # 문자 방식 — 소유자 실행 제거, 나머지 읽기 추가
root@linux-master:~# ls -l lin.sh
-rw-r--r--  1 ihd ihd 1079 Jan 27 16:29 lin.sh

    ⚠️ 디렉터리에서 x는 "실행"이 아니라 그 디렉터리 안으로 들어갈 수 있는 권한입니다. w는 디렉터리 안에 파일을 만들거나 지울 수 있는 권한이고요.

    1-3. 특수 권한 — SetUID · SetGID · Sticky Bit

    특수 권한숫자기호의미
    SetUID4000s (소유자 자리)실행하는 동안 파일 소유자의 권한으로 동작
    SetGID2000s (그룹 자리)실행하는 동안 파일 그룹의 권한으로 동작. 디렉터리에 걸면 그 안에 생기는 파일의 그룹이 디렉터리 그룹으로 지정됨
    Sticky Bit1000t (기타 자리)누구나 파일을 만들 수 있지만 삭제는 소유자와 root만. 공용 디렉터리용
    • 실행 권한(x)이 있는 파일에 걸면 소문자 s/t, 없는 파일에 걸면 대문자 S/T로 표시됩니다.
    • 대표 예시 — /usr/bin/passwd에는 SetUID가 걸려 있습니다. 일반 사용자가 자기 비밀번호를 바꾸려면 root 소유인 /etc/shadow를 고쳐야 하기 때문입니다.
    • 대표 예시 — /tmp에는 Sticky Bit가 걸려 있습니다. 누구나 임시 파일을 만들되 남의 파일은 못 지우게 하려고요.
    bash
    root@linux-master:~# ls -l /usr/bin/passwd  # 소유자 자리에 s → Set-UID
-rwsr-xr-x. 1 root root 27856 Apr  1  2020 /usr/bin/passwd
root@linux-master:~# ls -ld /tmp  # 기타 자리에 t → Sticky Bit
drwxrwxrwt. 15 root root 4096 Aug  3 09:12 /tmp
root@linux-master:~# chmod 2775 /project  # Set-GID 부여
root@linux-master:~# ls -ld /project
drwxrwsr-x. 2 root project 6 Aug  3 09:15 /project

    시험 단골 계산 — chmod 3770 /project

    • 맨 앞 3 = SetGID(2) + Sticky Bit(1)
    • 뒤 770 = 소유자 rwx, 그룹 rwx, 기타 사용자 없음
    • 결과: project 그룹원은 자유롭게 파일을 만들되 자기가 만든 파일만 삭제할 수 있고, 새로 만든 파일의 그룹은 자동으로 project가 됩니다.

    1-4. umask — 새로 만들 때의 기본 권한

    • 기본 권한: 파일 666, 디렉터리 777 (파일에 x가 기본으로 안 붙는 게 포인트)
    • 실제 권한 = 기본 권한 − umask 값
    • umask 0022 → 파일 644, 디렉터리 755
    • umask -S → 숫자 대신 u=rwx,g=rx,o=rx 처럼 문자로 표시
    • 맨 앞자리 숫자는 특수 권한 자리입니다.

    1-5. 마운트와 파일 시스템 만들기🔥 빈출 29문항

    명령설명
    mount장치를 디렉터리에 연결. -t로 파일 시스템 유형 지정
    mount -t ext4 /dev/sdb1 /data
    umount연결 해제. USB·CD는 반드시 umount 후 제거
    eject이동식 장치 꺼내기 (내부적으로 umount를 먼저 수행)
    fdisk파티션 생성·삭제·타입 변경. -l 파티션 테이블 출력
    mkfs파일 시스템 생성(포맷). -t로 유형 지정
    mke2fsext2/3/4 전용 포맷. -j를 붙이면 저널링이 켜져 ext3으로 생성

    작업 순서: fdisk로 파티션 나누기 → mkfs·mke2fs로 포맷 → mount로 연결

    fdisk 파티션 타입 ID — Linux 83 / Swap 82 / LVM 8e / RAID fd

    mount -o remount,rw /home — 이미 마운트된 /home을 읽기·쓰기 모드로 다시 마운트

    1-6. 점검·복구 — fsck 계열

    • fsck — 파일 시스템 무결성 점검·복구. 손상된 파일은 /lost+found로 연결됩니다.
    • e2fsck — ext2/ext3/ext4 전용 점검·복구
    • xfs_repair — XFS 전용 점검·복구

    ⚠️ /lost+found가 나오면 fsck를 떠올리세요.

    1-8. 디스크 쿼터 (사용량 제한)자주 16문항

    • quota — 사용자의 현재 사용량·제한 확인
    • quotacheck — 파일 시스템을 훑어 쿼터 파일 생성·확인·수정
    • edquota — 편집기(vi)를 열어서 할당량 설정. -p는 다른 사용자 설정을 그대로 복사
      edquota -p bookmark ihd (bookmark의 설정을 ihd에 동일 적용)
    • setquota — 편집기 없이 명령행에서 바로 설정
      setquota -u ihd 20M 30M 0 0 /home (블록 soft/hard, inode soft/hard)
    • repquota — 시스템 전체 쿼터 보고서 출력
    • xfs_quota — XFS용. -x -c 옵션과 함께 사용
    • quotaon / quotaoff — 쿼터 활성화·비활성화

    ⚠️ edquota(편집기 사용) ↔ setquota(명령행 직접)의 대비가 자주 출제됩니다.

    1-11. RAID와 LVM자주 20문항

    RAID — 디스크 여러 개를 묶어 성능이나 안정성을 얻는 기술

    레벨방식최소 디스크특징
    RAID 0스트라이핑2개속도만. 백업 기능 없음

    7-3. DISPLAY 환경 변수와 원격 실행

    사설 IP 대역

    • A — 10.0.0.0 ~ 10.255.255.255
    • B — 172.16.0.0 ~ 172.31.255.255

    루프백 주소 127.0.0.1은 A 클래스입니다. 0.0.0.0은 디폴트 경로, 255.255.255.255는 브로드캐스트.

    서브네팅 계산법 — C 클래스에서 마스크가 255.255.255.192인 경우

    • 256 − 192 = 64 → 한 서브넷의 크기
    • 256 ÷ 64 = 4개의 서브넷
    • 서브넷당 사용 가능한 호스트 = 64 − 2 = 62개 (네트워크 주소·브로드캐스트 제외)

    비트 수 — IPv4 32비트, IPv6 128비트, MAC 주소 48비트

    IPv6 특징 — 주소 공간 확장, 클래스 구분 없음, 패킷 출처 인증·비밀 보장, 흐름 제어 지원
