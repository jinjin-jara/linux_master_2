# 📘 리눅스마스터 2급 1차 · 7일 벼락치기 가이드

리눅스마스터 2급 1차 실기(필기) 시험을 일주일 안에 준비해야 하는 사람들을 위한
**웹 기반 벼락치기 가이드 + 문제풀이 사이트**입니다.

정리 자료를 눈으로 읽기만 하는 게 아니라, **직접 풀어보면서 감을 잡을 수 있게** 만들었어요.

> ⚠️ 개인이 만든 **비공식 정리 자료**입니다. 실제 시험 내용과 다를 수 있으니 참고용으로만 활용해주세요.

---

## ✨ 주요 기능

### 📖 스터디 가이드
- 7개 챕터, 31개 섹션으로 구성된 개념 정리 (리눅스 개요 → 디렉토리 → 파티션 → 부팅 → 계정 → 명령어 → 네트워크)
- 어려운 개념은 비유로 풀어서 설명, 시험에 자주 나오는 "함정 포인트" 별도 표시
- 명령어 파트에는 **실제 터미널 창처럼 생긴 실습 예시**가 들어있어서, 명령어 하나하나가 실제로 어떻게 동작하는지 눈으로 볼 수 있어요 (프롬프트 경로/유저도 `cd`, `su -` 등에 따라 실시간으로 바뀝니다)

### 📝 기출문제 풀이 (사지선다 270제)
- 반복 출제된 기출문제를 카테고리별(설치/파티션/부팅/계정/명령어/네트워크/쉘 등)로 골라서 풀거나, 전체를 순서대로 풀 수 있어요
- 정답을 고르면 맞았든 틀렸든 **해설이 바로** 나옵니다
- **틀린 문제만 다시 풀기** — 완주 여부와 상관없이 언제든 가능
- 문제 풀이 중에도 카테고리를 바로 전환할 수 있어요

### 🧠 마지막 점검 OX 문제 (34제)
- 자주 헷갈리는 함정 포인트를 O/X로 직접 판단해보는 코너
- 기출문제 풀이와 동일한 UX (해설 항상 표시, 틀린 문제 재도전)

### 🔖 북마크 & 진행 상황 저장
- 챕터/섹션마다 북마크 아이콘으로 표시 → 사이드바에 "내 북마크"로 모아서 바로가기
- 퀴즈 진행 상황·점수도 자동 저장 (새로고침해도 유지)
- 전부 **브라우저 localStorage**에만 저장되고, 서버로 전송되지 않습니다

### 🔍 검색
- 가이드 본문 + 기출문제 + OX문제까지 한 번에 검색
- 클릭하면 해당 섹션/탭으로 바로 이동
